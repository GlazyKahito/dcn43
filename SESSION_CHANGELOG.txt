================================================================================

system launcher for "Intelligent Network Design, Simulation & Fault Diagnosis System"
(Course ET301 Computer Networks & Diagnostics, K J Somaiya School of Engineering).

3. INTELLIGENT NETWORK DIAGNOSTICS CONSOLE
================================================================================
File: components/Diagnostics/NetworkDiagnosticsModule.tsx

A dedicated diagnostic triage console where students select real-world failure scenarios:
- 6 Interactive Scenarios:
  1. No Internet / Default Gateway Unreachable (ARP reply drop)
  2. DNS Hostname Resolution Failure (Port 53 daemon drop / SERVFAIL)
  3. High Latency & Bufferbloat Along Transit Link (>500ms RTT)
  4. Duplicate IP Address Conflict (MAC flapping & 50% packet loss)
  5. DHCP Pool Exhaustion (APIPA 169.254.x.x RFC 3927)
  6. Firewall ACL Dropping TCP Port 80 (HTTP 3-way handshake block)
- Systematic Engineering Triage Flow:
  Symptoms → Hypotheses → Simulated Terminal Probes (ping, tracert, ipconfig, nslookup, arp, telnet)
  → Detected Root Cause → Apply Fix & Re-Probe → Verified Resolution.

5. ANIMATED STEEL FLUID / LIQUID METAL WEBGL2 BACKGROUND
================================================================================
Files: components/SteelFluid/SteelFluidCanvas.tsx, components/SteelFluid/SteelFluidBackground.tsx

- Pure Metallic Shader Design:
  * Strict monochrome metallic palette: silver reflections, brushed steel midtones, gunmetal shadows,
    and near-black graphite base. No neon or rainbow gradients.
  * 4-octave Fractional Brownian Motion (FBM) with 2nd-order domain warping.
  * Normal vector calculation via finite differences for physical 3D curvature.
  * Dual specular highlights (primary directional spec^38.0 + secondary ambient spec^16.0).
  * Fresnel rim lighting ((1.0 - n.z)^2.8) and micro-brushed grain texture.
  * Hypnotic, slow fluid flow (uTime * 0.07).
  * Damped pointer flow: global mouse movement subtly displaces the fluid field.
- Layering & Contrast Protection:
  * Base Graphite Canvas → WebGL Steel Fluid → Dark Veil & Radial Vignette → UI / Wheel.
  * Fully pointer-events-none; zero interference with clicks, drags, or card selection.
- Fallback & Optimization:
  * CSS animated conic/radial gradient fallback for non-WebGL2 devices.
  * DPR clamped to 1.0 on mobile devices for smooth 60fps execution.
  * Respects prefers-reduced-motion.
